# UMBRAL — Cocina Cubana · Boston

Premium high-end Cuban restaurant website concept, designed directly for GitHub Pages within the The Launch Era public demos collection.

## Pages
- URL path: /demos/umbral/
- Main entry: index.html (static HTML)
- Style: styles.css (responsive, editorial, mobile-first)
- Interaction: app.js (EN/ES language, gallery, client-side booking preview)
- Images: images/facade.jpg and images/booth.jpg are **original user-provided photographs** copied at original resolution without transcoding.

## Content integrity
This is a **concept demo**, not an operating restaurant.
- Do not present any opening hours, street address, menu price, phone or active reservation provider as real.
- The reservation widget is a **local front-end preview** only. It does not create reservations, email guests, charge cards or persist personal data. A production booking provider and real restaurant details must be connected before relabeling as a real reservations service.
- Original images imported: **2** of the intended 16; remaining gallery and dish images use externally hosted editorial placeholders.
- Image captions and alt text distinguish originals from illustrative placeholders. Replace remote placeholder images only when the remaining approved original assets are available.
- Hero image: images/facade.jpg (original user image)
- Atmosphere image: images/booth.jpg (original user image)
