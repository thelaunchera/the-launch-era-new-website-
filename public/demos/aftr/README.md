# AFTR. LAS VEGAS — Chrome Afterglow

Fictional premium nightclub concept demo built around the approved **Chrome Afterglow** brand direction.

## Explore
Open `index.html` in a browser or serve this folder as static files. No install, account, backend, payment key or database required.

For a local server:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.

## Sections
- Cinematic hero / Electric After Dark
- Tonight's Events and Weekly Lineup
- Experience / nightlife atmosphere
- VIP Table Reservations
- Special Offers, Guest List, Tickets & Experiences
- Simulated interactive forms and 21+ acknowledgment
- Mobile, tablet and desktop layouts, keyboard-friendly controls, reduced-motion handling

## Brand identity
`#0B0911` Midnight Black · `#9A6AFF` Electric Violet · `#FF3F9D` Hot Magenta · `#C6C9D4` Chrome Silver · `#D9FF52` Acid Lime (sparingly).

Photography created as separate original concept images, optimized WebP files in `/assets`.

**This is a concept demonstration, not a real nightclub.** Forms only simulate confirmations; the website stores no names, requests, or payment details. Tickets, promotions and lineups are illustrative. No legal venue address is implied.
