# The Launch Era · Proceso oficial de producción de demos

Actualizado: 4 de noviembre de 2026. Instrucción de la propietaria para **cada demo nuevo**.

## Orden obligatorio

1. **Crear en AppDeploy.** Construir el sitio completo, su diseño editorial, fotos propias, funcionalidad de muestra y adaptación móvil. Comprobar el enlace de vista previa.
2. **Transferir al repositorio de demos.** Guardar el código y las fotos individuales en `public/demos/<slug>/` de `thelaunchera/the-launch-era-new-website-`, o preservar un repositorio propio ya aprobado. Mantener cada marca aislada. Asegurar que el enlace de GitHub publicará y abrirá la web operativa, no únicamente el árbol de código.
3. **Registrar en The Launch Era Studio.** Añadir la ficha correspondiente a **Demos terminados** del repo `thelaunchera/todavia-estoy-a-tiempo` (`estudio-control/src/FinishedDemos.tsx`). Guardar portada, URL pública, URL del repositorio, carpeta de Drive por marca, todas las imágenes individuales, prompts de imagen originales cuando existan (de referencia si no), prompts de reconstrucción por pasos, materiales y notas. Probar todos los enlaces.
4. **Ofrecer publicación opcional en el Aula.** En Studio, mostrar **«Agregar al Aula»** dentro de la ficha del demo terminado. **No activar por defecto.** Solo la propietaria decide qué demos conceptuales compartir en el Aula de alumnos. Permitir «Quitar del Aula» y actualización de fotos/prompts sin borrar el kit privado.

## Restricciones

- La publicación en GitHub/Studio no equivale a permiso para publicar en el Aula.
- Los demos de clientes reales no pueden entrar al Aula ni exponer datos, imágenes, formularios o accesos privados sin autorización expresa.
- Nunca mezclar recursos de marcas diferentes, ni el Studio privado con el Carousel Studio del Lab comercial.
- Una entrega no está terminada si faltan imágenes aprobadas, prompts, pasos, fuentes, URL funcional o revisión móvil.
- Si un paso falla, indicar el paso pendiente; no afirmar que todo el proceso quedó completo.

Este flujo se aplica cada vez que la propietaria diga: **«haz un demo»**.
