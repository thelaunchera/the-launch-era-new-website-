# Self Love Gym · Coach Desk demo

Interactive bilingual preview for The Launch Era. The published GitHub Pages route stores fictional edits only in the visitor's browser. It has no live payment processing, automatic messaging, or private database. The button to open a private workspace leads to the AppDeploy version.

Build: `npm install && npm run build`. The Vite base path is `/demos/self-love-gym-coach-desk/` for publication inside the active The Launch Era site.

The design uses an original dark plum sidebar, pink and purple action surfaces, clear membership records, and a mobile navigation menu. Behance and Pinterest examples were used only as layout references; no third-party artwork was copied.
